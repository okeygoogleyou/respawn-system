# Заметки по развитию Системы

Автор проекта: **okeygoogle**.

## Сетевой принцип

`SystemPayload` переносит бинарные сообщения с номером протокола. Текущая версия протокола: `2`.

Сервер не доверяет клиенту в вопросах:

- координат меток;
- ролей;
- редактирования системных профилей;
- доступа к чужим тикетам;
- внутренних заметок поддержки.

## Где менять темы

`src/client/java/ru/okeygoogle/respawnsystem/client/ui/ThemeCatalog.java`

Тема содержит основной акцент, фон, панели, основной/приглушённый текст и цвет опасности.

## Где менять поведение статусов

`src/client/java/ru/okeygoogle/respawnsystem/client/ui/StatusStyle.java`

Там задаются цвет и предупреждение. Скрытие/архивирование отдельных данных профиля находится в `SystemScreen#renderProfile`.

## Где добавлять системные поля

Поле нужно добавить одновременно в:

1. серверную `ProfileData`;
2. сохранение/загрузку `DataStore`;
3. сериализацию `ServerWire#writeProfile`;
4. клиентскую `ProfileData`;
5. чтение `ClientSystemState#readProfile`;
6. при необходимости `Wire#adminProfileUpdate`;
7. интерфейс `SystemScreen`.

После изменения бинарного формата увеличьте `PROTOCOL` одновременно в `ServerWire` и клиентском `Wire`.
