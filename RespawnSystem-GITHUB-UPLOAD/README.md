# Respawn System — Fabric 26.2

**Автор: okeygoogle**  
Версия проекта: **0.2.0**  
Minecraft: **26.2**  
Fabric Loader: **0.19.4+**  
Fabric API: **0.158.0+26.2** или совместимая более новая  
Java: **25**

Это **один Fabric-мод**, а не плагин. Один и тот же собранный JAR кладётся:

- игрокам в папку `mods` модовой сборки;
- на Fabric-сервер в папку `mods`.

## Что уже реализовано

### Первый вход
После входа на сервер клиент получает состояние Системы. Если профиль ещё не зарегистрирован, поверх игры открывается обязательное окно:

> Добро пожаловать!  
> Введите пожалуйста свой никнейм.

Никнейм задаётся игроком только при первой регистрации. После этого системное имя меняет только администрация. Дубли системных никнеймов блокируются сервером.

### Окно Системы
По умолчанию открывается клавишей **R**. Клавишу можно переназначить в стандартных настройках управления Minecraft.

Вкладки:

- **Профиль** — аватар скина, системное имя, раса, происхождение, фракция, уровень доступа, статус, способности, особенности и декоративная подпись;
- **Игроки** — список зарегистрированных профилей;
- **Связь** — общий внутренний чат Системы;
- **Метки** — общие координатные метки игроков;
- **Поддержка** — собственные тикеты игрока;
- **Оформление** — тема, акцентный HEX-цвет и декоративная подпись;
- **Управление** — появляется только у ADMIN/OWNER/OP;
- **Центр поддержки** — появляется только у MODERATOR/ADMIN/OWNER/OP.

### Динамические статусы
Вид и содержимое профиля меняются от текста статуса. Встроены реакции на:

- `АКТИВЕН`;
- `НЕСТАБИЛЕН`;
- `АНОМАЛИЯ`;
- `ПОТЕРЯН`;
- `МЁРТВ` / `НЕАКТИВЕН`;
- `НАБЛЮДАЕМЫЙ`;
- `НЕОПОЗНАННЫЙ`.

Например, неопознанный профиль скрывает расу/происхождение/фракцию, потерянный показывает потерю сигнала, а мёртвый/неактивный переводит способности в архивный режим.

### Права
Внутренние роли:

`PLAYER → HELPER → MODERATOR → ADMIN → OWNER`

- **PLAYER** — обычный игрок;
- **MODERATOR+** — доступ к Центру поддержки;
- **ADMIN+** — редактирование системных профилей и системные объявления;
- **OP** Minecraft автоматически считается `OWNER`, даже если в сохранённом профиле стоит обычная роль.

Администратор без OP не может назначить `ADMIN`, `OWNER` или равную себе роль. `OWNER` может назначить только OP.

### Что игрок НЕ может изменить
Сервер проверяет права, поэтому модифицированный клиент не должен позволить игроку самостоятельно менять:

- системный никнейм после регистрации;
- расу;
- происхождение;
- статус;
- фракцию;
- способности;
- особенности;
- роль доступа;
- скрытую заметку администратора.

Игрок меняет только оформление своего профиля.

### Поддержка
Игрок видит только собственные обращения. Центр поддержки видит весь список обращений и позволяет:

- открыть тикет как отдельный чат;
- ответить игроку;
- взять обращение в работу;
- закрыть обращение;
- оставить внутреннюю заметку.

Внутренние заметки не просто скрываются интерфейсом — сервер вообще не отправляет их обычному игроку.

### Общие метки
При создании метки координаты берутся **на сервере** из реального положения игрока. Переданным клиентом координатам сервер не доверяет. Игрок может удалить собственную метку, администратор — любую.

## Оформление

Встроены темы:

- Системная;
- Багровая;
- Фиолетовая;
- Монохром.

Игрок дополнительно выбирает свой акцентный цвет в формате `#RRGGBB`.

После первого запуска создаётся:

`config/respawn-system-ui.properties`

Доступные параметры:

```properties
showGrid=true
gridSpacing=28
brandText=RESPAWN // СИСТЕМА
playUiSounds=true
```

Это позволяет менять сетку, надпись в шапке и звуки без перекомпиляции.

## Данные сервера

Сервер хранит состояние в:

`config/respawn-system/data.json`

Рядом создаётся резервная копия:

`config/respawn-system/data.backup.json`

В JSON сохраняются профили, роли, способности, статусы, чат, метки и тикеты.

## Звуки

Для интерфейса выбран бесплатный набор **Kenney Interface Sounds**, лицензия **CC0**.

Источник и раскладка файлов описаны в `docs/SOUND_SOURCES.md`.

`BUILD_WINDOWS.bat` сам попробует скачать и положить выбранные OGG перед сборкой. Отдельный `INSTALL_SOUNDS_WINDOWS.bat` оставлен как запасной способ для тех, у кого уже установлен Python 3.

Если OGG не установлены, интерфейс использует стандартный Minecraft `ui.button.click` как fallback и не должен падать из-за отсутствующих файлов.

## Сборка на Windows

Самый простой способ — **двойной клик по `BUILD_WINDOWS.bat`**.

Скрипт не требует системной установки Java или Gradle. Он сам:

1. скачает portable **Temurin JDK 25** в `.build-tools`;
2. скачает **Gradle 9.5.1** и проверит официальный SHA-256;
3. попробует добавить выбранные CC0-звуки Kenney;
4. выполнит `clean build`;
5. положит готовый файл в:

`release/RespawnSystem-okeygoogle-26.2-0.2.0.jar`

Если OpenGameArt временно недоступен, сборка всё равно продолжится со стандартным UI-звуком Minecraft.

## Установка готового JAR

1. Установите Fabric Loader для Minecraft 26.2.
2. Добавьте Fabric API подходящей версии.
3. Один и тот же `respawn-system-26.2-0.2.0.jar` положите в `mods` серверной сборки и в `mods` каждого клиента.
4. Запустите сервер и клиенты.
5. При первом подключении новый игрок увидит регистрацию.
6. После регистрации Система открывается клавишей `R`.

## Структура проекта

- `src/main/java` — общая и серверная логика, сетевой протокол, хранение данных, права;
- `src/client/java` — интерфейс, клавиша, клиентское состояние;
- `src/main/resources` — `fabric.mod.json`, языки, `sounds.json`;
- `tools` — установщик CC0-звуков.

## Важное про безопасность

Все действия, влияющие на игровые данные Системы, проверяются сервером. Клиент отвечает за интерфейс и запросы, но окончательное решение о правах, координатах, тикетах и изменении профиля принимает серверная часть того же Fabric-мода.

## Сборка через GitHub Actions

В проект включён `.github/workflows/build.yml`. После загрузки проекта в ветку `main` GitHub автоматически запускает сборку на Java 25 и Gradle 9.5.1. Готовый игровой JAR публикуется в артефакте `RespawnSystem-okeygoogle-26.2` на странице запуска Actions.
